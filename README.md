# Projeto E-Commerce - Disciplina de Javascript
## Visão Geral

Este é um projeto em grupo desenvolvido para a disciplina de JavaScript na Unifacisa
O projeto consiste em um site de e-commerce simples, construído utilizando JavaScript, HTML e Tailwind CSS.
O objetivo principal foi praticar desenvolvimento front-end dinâmico, integração com APIs e manipulação do DOM usando JavaScript.

## Funcionalidades

### Listagem Dinâmica de Produtos:
Os produtos são renderizados dinamicamente na página HTML usando JavaScript, permitindo atualizações sem alterar manualmente o HTML.

### Carrinho de Compras:
Usuários podem adicionar produtos ao carrinho, visualizar os itens e remover produtos dinamicamente.

### Integração com API de CEP:
O site está integrado com uma API de CEP para buscar e preencher automaticamente informações de endereço com base no CEP digitado pelo usuário, simulando uma experiência de checkout real.

### Design Responsivo:
Utilizando Tailwind CSS, o site se adapta a diferentes tamanhos de tela, incluindo dispositivos móveis e desktops.

## Tecnologias Utilizadas

JavaScript (Vanilla) – Para manipulação do DOM, eventos e integração com API.

HTML5 – Estrutura semântica do site.

Tailwind CSS – Estilização e design responsivo.

API de CEP – Para buscar informações de endereço a partir do CEP
